# One pill per message, not per conversation

A Reply loop is one conversation, and it stays open until you reply, its notification goes, or 12 hours pass. The pill was limited to one per loop, so once a pill had shown for Rahul, nothing Rahul wrote afterwards could get a pill until that loop closed. If you left the pill, put the phone down and Rahul wrote again, the next unlock showed a chip for the new message, but drift never brought it back. Testing with the same friend twice hit this every time.

Now a new message in the loop (a later message timestamp, not the app posting the same one again) clears the "pill already shown" mark. One pill per message keeps the pill from coming back for something you already passed over, without hiding what someone writes next. The 10-minute gap between any two pills still applies.

The decision log also names why a pill was held, instead of "one pill per loop" for every case: its pill already showed for this message, its chip was swiped, its app cleared the notification, Earmark is paused, or the 10-minute gap and how long is left.
