# The applicationId is com.sweepiesoftie.earmark

The app ships as `com.sweepiesoftie.earmark`, under the Sweepie Softie name from the pitch deck, rather than a neutral `app.earmark`. The ID can't change after people install the app without breaking updates, so it is fixed from v0.1. Kotlin packages are `com.sweepiesoftie.earmark.core` for `:core` and `com.sweepiesoftie.earmark` for `:app`.
